## 🚀 Featured Projects

### [HootPR - AI Code Reviewer for GitHub & GitLab](https://hootpr.sahell.in)
Each PR is cloned into a sealed, network-cut sandbox, analyzed with Semgrep and tree-sitter, and investigated by tool-using LLM agents. A judge model drops any finding not backed by evidence, so only patch-ready comments reach the PR. Also autofixes code, generates tests and repairs CI from failed job logs.
`Python` `LangGraph` `FastAPI` `Celery` `PostgreSQL` `pgvector` `Redis` `Docker` `MCP` `Next.js` `TypeScript`

### [Assay - AI Equity Research Agent](https://assay.sahell.in)
Takes a US ticker, reads financials and SEC EDGAR filings, computes every ratio in Python, benchmarks against peers and scores 27 metrics across five dimensions to produce a cited BUY / HOLD / SELL memo. The LLM writes the argument but never produces numbers or picks the rating.
`Python` `LangGraph` `FastAPI` `PostgreSQL` `pgvector` `Redis` `ARQ` `OpenAI API` `Next.js` `TypeScript`
